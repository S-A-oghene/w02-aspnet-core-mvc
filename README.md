# W02 Assignment — ASP.NET Core MVC

**Application:** Eseoghene Movies  
**Framework:** ASP.NET Core MVC on .NET 10 LTS  
**Database:** SQLite with Entity Framework Core  
**Editor instructions:** Visual Studio Code (the tab required by the BYU-Idaho assignment)

This repository contains the completed source-code structure for the W02 ASP.NET Core MVC assignment, an absolute-beginner setup guide, a tutorial-to-code map, a test checklist, and an Azure App Service deployment guide.

> **Personalisation step:** The database starts with the three titles selected by me: **The Lord of the Rings**, **Merlin**, and **Interstellar**. The Lord of the Rings record identifies the first film in the trilogy. Merlin is the BBC fantasy television series (not a feature film); it is retained because the student explicitly selected it.
